## 1. Brand Palette & Colors

| Role | Color Name | Hex Code | Purpose |
|---|---|---|---|
| **Primary** | Electric Indigo | `#4338CA` / `#4F46E5` | Core brand identity, primary buttons, study action |
| **Secondary** | Vibrant Teal | `#0D9488` / `#2DD4BF` | Category badges, complementary accents |
| **Tertiary** | Warm Amber | `#D97706` / `#F59E0B` | Highlights, badges, motivation tags |
| **Success** | Emerald Green | `#059669` / `#10B981` | "Got It / Remembered" action, mastery rates |
| **Practice** | Coral Rose | `#E11D48` / `#F43F5E` | "Need Practice" action, difficult card indicators |
| **Background (Light)** | Slate Frost | `#F8FAFC` | Main app background (Light mode) |
| **Background (Dark)** | Midnight Slate | `#090D16` | Main app background (Dark mode) |

---

## 2. Typography Guidelines
- **Title / Headlines:** High legibility sans-serif with bold weight for front-of-card questions.
- **Body Text:** Clear neutral body font for definitions and explanations with comfortable line height.
