# Changelog

All notable changes to Flashlet will be documented in this file.

## [1.0.0] - 2026-10-09
### Added
- Initial production-ready release of Flashlet.
- Local-first Room Database storage for decks and flashcards.
- Smooth 3D tap-to-flip flashcard study interface with mirror correction.
- Study session mode with active recall grading ("Got It" vs "Need Practice").
- Targeted study sessions for revisiting difficult cards only.
- Comprehensive deck and card management (create, edit, duplicate, search, delete).
- Portable JSON export and import for seamless deck sharing between devices.
- Social media study score and milestone sharing via native Android sharesheet.
- Preloaded sample decks: Essential English Vocabulary, Bangla Essentials, World Capitals, and Computer Science Concepts.
- Bilingual localization support (English & Bangla strings).
- Centralized AdMob configuration (`AdConfig`) with Google test identifiers.
- Material Design 3 theming with dynamic colors and dark mode support.
- Unit and Robolectric JVM test coverage.
